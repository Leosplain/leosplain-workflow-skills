# Example: one-step-test

## Before
Two prompt versions were changed at once: priority wording and folder location. Nobody could tell which change caused the improvement.

## After
Kept the folder fixed, changed only the priority wording, and reran the same task.

## Result
The change became attributable instead of accidental.

## Limitation
If the source set is still mixed, one-step testing only tells you which part failed first; it does not repair missing evidence.
