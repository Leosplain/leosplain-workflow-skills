# Research notes

These skills were designed around repeated workflow failures:

- Old and current versions getting mixed together
- Evidence being assumed instead of verified
- Summaries filling gaps that were never written
- Multiple changes being bundled into one run
- Outputs drifting beyond the evidence boundary

The pack does **not** claim benchmark scores, universal accuracy, or model superiority.
Its goal is narrower: make failure visible early, then stop the model from inventing the rest.
